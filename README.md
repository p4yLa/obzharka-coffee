# Обжарка — сайт кофейни (демо)

Демо-проект для портфолио. Кофейня вымышленная, все реквизиты и контакты — заглушки.
Разработка: Telegram [@p4yLa](https://t.me/p4yLa).

Чистые HTML, CSS и JavaScript: без фреймворков, сборщиков и внешних запросов. Шрифты и фото лежат в проекте.

## Что умеет сайт

- Статус «Открыто / Закрыто» в шапке по московскому времени, в каком бы поясе ни был посетитель.
- Меню с вкладками (работают с клавиатуры) и переключатель 250 / 350 мл, который меняет цены на кофе.
- Зерно недели: дата обжарки считается автоматически (ближайший четверг), заказ пачки в модальном окне.
- Галерея с лайтбоксом: свайп, стрелки клавиатуры, Esc.
- Бронь стола: дата не раньше сегодняшней и не дальше 30 дней, слоты по 30 минут в часы работы выбранного дня. На сегодня прошедшие слоты скрыты.
- Маска телефона `+7 (XXX) XXX-XX-XX`, проверка полей на лету, понятные ошибки, экран успеха.
- Согласие на обработку ПДн по 152-ФЗ в каждой форме, cookie-баннер, который запоминается в `localStorage`.
- Если JS не загрузился, весь контент виден: анимации и вкладки включаются только при классе `.js`.
- Учитывается `prefers-reduced-motion`.

## Структура

```
index.html      главная

fonts/          Playfair Display 600/700, Golos Text 400/500 (woff2, латиница + кириллица)

```

## Как запустить локально

Откройте папку в VS Code и запустите расширение **Live Server**, либо в терминале:

```bash
npx serve .
```

Открывать `index.html` двойным кликом тоже можно, но тогда страница 404 не будет работать (у неё абсолютные пути).

## Публикация на Netlify

1. Зайдите на [app.netlify.com](https://app.netlify.com) → **Add new site → Deploy manually**.
2. Перетащите папку проекта в окно браузера. Готово.

## Как подключить настоящие заявки (Netlify Forms)

Сейчас формы ничего не отправляют: это демо. Чтобы заявки приходили на почту через Netlify, добавьте тегу формы один атрибут `data-netlify="true"` (и `name`):

```html
<form ... name="booking" data-netlify="true">
```

Затем в `js/main.js`, в функции `setupForm`, после строки с комментарием «Демо: данные никуда не уходят» отправьте данные:

```js
fetch('/', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams(new FormData(form)).toString()
});
```

Заявки появятся в панели Netlify в разделе **Forms**. Там же можно включить уведомления на почту.

> Важно для 152-ФЗ: серверы Netlify находятся за рубежом. Для настоящего российского бизнеса данные граждан РФ нужно первично записывать в базу на территории России: например, отправлять заявки в свой бэкенд, в Telegram-бота на российском VPS или в CRM с серверами в РФ (amoCRM, Битрикс24).

## Что заменить перед запуском настоящего сайта

- Домен `obzharka.example` → настоящий: в `canonical`, `og:url`, `og:image`, JSON-LD, `robots.txt`, `sitemap.xml`.
- Телефон, адрес, ИНН, ОГРН — в `index.html`, `privacy.html` и JSON-LD.
- Ссылки на мессенджеры (сейчас `#`) и ссылку на отзывы в Яндекс Картах.
- Раскомментировать и вставить код **Яндекс Метрики** и мета-тег **Яндекс Вебмастера** в `<head>`.
- Текст политики — согласовать с юристом.
